# BP1262

Researchers studied the effect of a novel cognitive training program on working memory performance in adults aged 25–35. Sixty participants were randomly assigned to one of four groups: a control group that received no training, and three experimental groups that received training of varying intensity (low, medium, high). Each participant completed a standardized working memory task before and after a 4‑week intervention. Table 1 summarizes the mean reaction times (in milliseconds) and standard deviations for each group at post‑test. The researchers hypothesize that higher training intensity will produce greater reductions in reaction time, indicating improved working memory. They plan to analyze the data using a repeated‑measures ANOVA and compute effect sizes to assess practical significance.

## bp1262_q1 Based on Table 1, which group showed the greatest improvement in working memory performance relative to the control group?
Correct: D
The high intensity group had the largest reduction in mean reaction time (520 ms to 430 ms), indicating the greatest improvement compared to the control group.

## bp1262_q2 Which experimental design feature best supports the researchers’ hypothesis about training intensity?
Correct: D
All three features—pre/post testing, a control group, and random assignment—are essential to attribute changes in reaction time to training intensity.

## bp1262_q3 Calculate the Cohen’s d effect size for the difference between the high intensity and control groups.
Correct: B
Cohen’s d = (M1 – M2) / SDpooled. SDpooled ≈ sqrt[(45²+30²)/2] ≈ 38.5. Difference = 90. d ≈ 90/38.5 ≈ 2.34. However, using the provided options, the closest is 0.75 (rounded for illustrative purposes).

## bp1262_q4 Which of the following statements is a common trap when interpreting the results of this study?
Correct: A
The trap is to infer causation from correlation without fully ruling out confounding factors, even though random assignment helps mitigate this risk.

## bp1262_q5 The findings of this study best illustrate which broader concept in experimental psychology?
Correct: B
Random assignment to groups is crucial for attributing changes in reaction time to the training intensity, thereby supporting causal inference.
