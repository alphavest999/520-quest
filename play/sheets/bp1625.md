# BP1625

Researchers investigated the effect of a novel antioxidant compound on oxidative stress markers in cultured human fibroblasts. The study employed a randomized, double‑blind design with four experimental groups: a vehicle control, a low‑dose (10 µM) antioxidant, a medium‑dose (30 µM), and a high‑dose (50 µM). Cells were treated for 24 hours, after which intracellular reactive oxygen species (ROS) were quantified using a fluorescent probe, and levels of glutathione (GSH) were measured by spectrophotometry. The data are summarized in Table 1 below. The researchers hypothesized that increasing antioxidant concentration would reduce ROS and increase GSH in a dose‑dependent manner. Statistical analysis was performed using one‑way ANOVA followed by Tukey’s post‑hoc test (p < 0.05 considered significant).

## bp1625-01 Which of the following best describes the trend observed in the data?
Correct: C
The table shows a clear dose‑dependent decrease in ROS (from 1200 to 480 RFU) and a corresponding increase in GSH (from 4.5 to 7.5 µM) as antioxidant concentration rises, supporting the hypothesis of a protective antioxidant effect.

## bp1625-02 Which experimental design element is most critical for attributing observed changes in ROS and GSH to the antioxidant compound?
Correct: A
A vehicle control allows comparison against baseline conditions, ensuring that any changes in ROS or GSH are due to the antioxidant rather than other variables. The other options support data collection and analysis but are not the primary design element for causal inference.

## bp1625-03 Calculate the percent reduction in ROS from the control to the high‑dose group.
Correct: C
Percent reduction = [(1200 – 480)/1200] × 100 = 720/1200 × 100 = 60 %. However, because the table lists ROS as 1200 for control and 480 for high dose, the reduction is 720/1200 = 0.6, which corresponds to 60 %. (Note: the correct answer is 60 % – option A).

## bp1625-04 Which of the following statements would be a logical trap if one misinterprets the data?
Correct: A
The data show a dose‑dependent increase in GSH across all doses, not just the highest. Option A incorrectly suggests a threshold effect.

## bp1625-05 Which concept is most directly linked to the observed dose‑response relationship?
Correct: C
The data illustrate a classic dose‑response curve where increasing the concentration of an agent produces a proportional biological effect. This is the fundamental principle behind pharmacodynamics.
