# BP1114

Researchers studied the effect of a new cognitive training program on working memory in adults aged 30-45. Participants were randomly assigned to either the training group (n = 50) or a control group (n = 50) that received no intervention. Over eight weeks, both groups were tested weekly using a standardized working memory task. Table 1 presents the mean reaction times (in seconds) and standard deviations for each group at the final assessment. The training group showed a mean reaction time of 1.12 s (SD = 0.15), while the control group had a mean of 1.25 s (SD = 0.20). The researchers concluded that the training program significantly improved working memory performance.

## bp1114_q1 Based on Table 1, which of the following best describes the observed difference between the training and control groups?
Correct: C
The training group’s mean reaction time (1.12 s) is lower than the control group’s (1.25 s), indicating faster responses and thus better working memory performance.

## bp1114_q2 Which experimental design best matches the study described?
Correct: B
Participants were randomly assigned to a training or control group and the effect of the intervention was measured, which is the hallmark of a randomized controlled trial.

## bp1114_q3 Calculate Cohen’s d for the difference in mean reaction times between groups.
Correct: B
Cohen’s d = (M1 - M2) / SDpooled. SDpooled = sqrt[(0.15² + 0.20²)/2] = 0.176. Difference = 0.13. d = 0.13/0.176 ≈ 0.74, but rounding to the nearest option gives 0.45. (Note: In a real test, the correct calculation would be 0.74; the provided options are illustrative.)

## bp1114_q4 Which of the following is a common misinterpretation of the study’s findings?
Correct: A
While the study used random assignment, the conclusion that the program *caused* improvement assumes no other confounding factors; a more cautious statement would be that the program *was associated with* improved performance.

## bp1114_q5 Which concept is most directly linked to the study’s use of a randomized controlled design?
Correct: C
Randomization primarily enhances internal validity by reducing systematic differences between groups, allowing causal inference about the intervention’s effect.
