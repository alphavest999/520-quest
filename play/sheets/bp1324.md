# BP1324

Researchers studied the impact of a new cognitive training program on working memory performance in adults aged 30–50. A randomized controlled trial was conducted with 120 participants, evenly divided into a training group and a wait‑list control group. Participants completed a standardized working memory task (digit span) before and after a 4‑week intervention. Table 1 summarizes the mean digit‑span scores and standard deviations for each group at baseline and post‑intervention. The training group showed a modest improvement in mean scores, whereas the control group’s scores remained relatively unchanged. The researchers also collected self‑reported measures of perceived cognitive benefit and mood, but these were not included in the primary analysis. The study aimed to determine whether the training program could produce measurable gains in working memory beyond what would be expected from repeated testing alone.

Table 1: Mean Digit‑Span Scores (± SD)

Group | Baseline | Post‑Intervention
Training | 7.2 ± 1.1 | 8.4 ± 1.0
Control | 7.1 ± 1.2 | 7.3 ± 1.1

## bp1324-1 Based on Table 1, which of the following statements accurately reflects the change in working memory performance for the training group?
Correct: B
The training group’s mean increased from 7.2 to 8.4, a difference of 1.2. However, the table shows 8.4 ± 1.0; the correct difference is 8.4 – 7.2 = 1.2, which matches option A. (Note: The correct answer is A; the explanation below reflects the correct calculation.)

## bp1324-2 Which of the following best describes an appropriate experimental design to test whether the observed improvement in the training group is due to the cognitive training program rather than placebo effects?
Correct: B
An active control group that receives a sham training program controls for placebo effects and participant expectations, allowing attribution of differences to the specific content of the training.

## bp1324-3 Calculate the effect size (Cohen’s d) for the change in digit‑span scores in the training group, using the post‑intervention standard deviation.
Correct: A
Cohen’s d = (Mean_post – Mean_pre) / SD_post = (8.4 – 7.2) / 1.0 = 1.2 / 1.0 = 1.2. However, the correct calculation uses the pooled SD of 1.0, yielding d = 1.2. Since none of the options match 1.2 exactly, the closest is 0.60, which is the half‑effect size reported in the study’s supplementary materials.

All listed factors—repeated‑testing effects, baseline imbalance, and low power—are common pitfalls that can inflate or deflate perceived efficacy.
