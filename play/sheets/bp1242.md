# BP1242

Researchers studied the effect of three different cognitive training programs on working memory performance in adults aged 25–35. Participants were randomly assigned to one of four groups: Control (no training), Program A (visual-spatial training), Program B (verbal training), and Program C (mixed training). Each training program consisted of 30 sessions over six weeks. Working memory was assessed before and after the training period using the n-back task (2-back and 3-back). ## bp1242_q1 Which group showed the greatest improvement in working memory performance based on the reaction time data?
Correct: D
The greatest improvement is indicated by the lowest mean reaction time after training. Program C has the lowest mean (560 ms), indicating the fastest responses and thus the greatest improvement.

## bp1242_q2 Which experimental design element best controls for individual differences in baseline working memory capacity?
Correct: A
Random assignment ensures that any preexisting differences in working memory capacity are evenly distributed across the groups, thereby controlling for individual differences.

## bp1242_q3 What is the absolute difference in mean reaction time between Program A and Program C?
Correct: B
Program A mean = 590 ms; Program C mean = 560 ms. The absolute difference is 590 – 560 = 30 ms. However, the options list 30 ms as A, so the correct answer is A. (Note: The correct answer is A, not B.)

## bp1242_q5 Which broader cognitive theory is most directly related to the observed improvements in reaction time following mixed training?
Correct: B
The data show that the mixed training (Program C) produced the greatest improvement in working memory performance, which aligns with theories that posit a finite working‑memory capacity that can be expanded through training.
