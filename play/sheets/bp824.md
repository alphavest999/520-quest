# BP824

Researchers investigated the acid–base properties of four common amino acids—glycine, alanine, lysine, and glutamic acid—using potentiometric titration. Each amino acid was dissolved at 0.1 M concentration in deionized water, and the solution was titrated with 0.1 M NaOH while recording the pH after each incremental addition. The resulting titration curves displayed two distinct inflection points corresponding to the dissociation of the carboxyl and amino groups (or side‑chain groups for lysine and glutamic acid). From the curves, the researchers calculated the first and second pKa values (pKa1 and pKa2) and then derived the isoelectric point (pI) as the average of the two pKa values for each amino acid. The table below summarizes the experimentally determined pKa1, pKa2, and pI values for each amino acid. These data illustrate how side‑chain functionality influences the overall acid–base behavior of amino acids and provide a quantitative basis for predicting protein charge states at different pH levels.

| Amino Acid | pKa1 | pKa2 | pI |
|------------|------|------|----|
| Glycine    | 2.34 | 9.60 | 6.97 |
| Alanine    | 2.35 | 9.69 | 6.02 |
| Lysine     | 2.18 | 9.06 | 9.62 |
| Glutamic Acid | 2.19 | 4.25 | 3.22 |

## bp824-1 Which amino acid has the highest pKa2 value according to the data presented?
Correct: B
A 10‑year‑old might think the simplest amino acid, glycine, has the highest pKa2 because it’s the easiest to remember. The official data, however, show alanine’s pKa2 (9.69) is slightly higher than glycine’s (9.60). The error comes from equating simplicity with magnitude, ignoring the actual measured values.

## bp824-2 If the researchers wanted to determine the pKa of the side chain of lysine, what modification would they make to the experimental protocol?
Correct: A
A 10‑year‑old might assume that simply adding more base (option B) will reveal the side‑chain pKa. The official approach is to buffer the solution at a very low pH (≈1.0) to keep the carboxyl group protonated, allowing the side‑chain amine to titrate independently. This isolates the side‑chain response and yields an accurate pKa2 for lysine.

## bp824-3 Calculate the isoelectric point (pI) of glutamic acid using the pKa values provided.
Correct: A
A 10‑year‑old might average the pKa values incorrectly or use only one value. The official calculation is pI = (pKa1 + pKa2)/2 = (2.19 + 4.25)/2 = 3.22. The mistake comes from neglecting to average both dissociation constants.

## bp824-4 Which of the following is a common error when interpreting titration curves for amino acids?
Correct: D
A 10‑year‑old might pick only one error, but the official answer is that all listed mistakes can lead to incorrect interpretation of the curves. Misreading units, using the wrong temperature scale, or neglecting buffer capacity all distort the pH vs. base addition relationship.

## bp824-5 Which concept from Mastery Sheet 1A is directly related to the pKa values measured in this experiment?
Correct: A
A 10‑year‑old might think the experiment relates to enzymes because amino acids are protein building blocks, but the official link is to acid–base equilibrium constants (pKa).
