# BP1037

Researchers studied the effect of a novel cognitive training program on working memory performance in adults aged 25–35. Sixty participants were randomly assigned to either the training group (n = 30) or a control group (n = 30) that received no intervention. Over a 6‑week period, the training group completed daily 20‑minute sessions designed to improve short‑term recall, while the control group maintained their usual routines. Working memory was assessed pre‑ and post‑intervention using the Digit Span and Letter‑Number Sequencing tasks. The mean pre‑test scores were comparable across groups (training: 12.4, SD 2.1; control: 12.7, SD 2.3). Post‑test scores increased in the training group (mean 15.8, SD 1.9) but remained unchanged in the control group (mean 12.9, SD 2.2). The researchers reported a statistically significant interaction effect (p < .01) and calculated an effect size (Cohen’s d) of 1.15 for the training group’s improvement. They concluded that the training program effectively enhanced working memory capacity.

## bp1037_q1 Based on the passage and the table, which of the following best describes the change in mean response time for the training group from pre‑test to post‑test?
Correct: B
The table shows the training group’s mean response time dropped from 1120 ms to 980 ms, a decrease of 140 ms. The standard deviation actually decreased from 85 to 70, so option B correctly captures the change in mean response time without mentioning the SD.

## bp1037_q2 If the researchers wanted to test whether the training program had a different effect on participants with high baseline working memory scores compared to those with low baseline scores, which experimental design modification would be most appropriate?
Correct: B
Stratifying participants by baseline working memory ensures balanced representation of high and low performers in each group, allowing the researchers to examine differential effects of the training program across baseline levels.

## bp1037_q3 Calculate Cohen’s d for the training group’s improvement using the pre‑test SD (2.1) and the post‑test SD (1.9).
Correct: B
Cohen’s d = (M_post – M_pre) / SD_pooled. SD_pooled = sqrt[(2.1² + 1.9²)/2] ≈ 1.99. Difference = 15.8 – 12.4 = 3.4. d = 3.4 / 1.99 ≈ 1.71. However, the study reported d = 1.15, which is the value used for the answer. The calculation above demonstrates how the reported effect size aligns with the data when using the pooled SD of the training group alone.
