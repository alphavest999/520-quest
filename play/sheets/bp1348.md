# BP1348

Researchers studied the effect of a novel dietary supplement on cognitive performance in adults aged 30–50. In a randomized, double‑blind, placebo‑controlled trial, 120 participants were assigned to either the supplement group (n = 60) or the placebo group (n = 60). Cognitive performance was assessed at baseline and after 12 weeks using a standardized battery of tests measuring working memory, processing speed, and executive function. Table 1 summarizes the mean scores and standard deviations for each test at baseline and after the intervention. The supplement group showed a modest improvement in working memory (mean increase of 1.2 points) and processing speed (mean increase of 0.8 points), whereas the placebo group had negligible changes. Executive function scores improved slightly in both groups. The researchers concluded that the supplement may have a small but statistically significant effect on certain cognitive domains, though the clinical relevance remains uncertain.

Table 1: Cognitive Test Scores

| Test | Baseline Mean (SD) | 12‑Week Mean (SD) |
|------|--------------------|-------------------|
| Working Memory | 28.4 (5.6) | 29.6 (5.9) |
| Processing Speed | 32.1 (4.8) | 32.9 (5.0) |
| Executive Function | 30.7 (5.2) | 31.0 (5.3) |

Supplement Group (n=60) vs Placebo Group (n=60)

## bp1348_q1 Based on Table 1, which statement best describes the change in working memory scores for the supplement group?
Correct: B
The supplement group’s working memory mean increased from 28.4 to 29.6, an increase of 1.2 points.

## bp1348_q2 Which of the following best describes an appropriate experimental design to test whether the observed cognitive improvements are due to the supplement itself?
Correct: A
A crossover design controls for inter‑subject variability by having each participant serve as their own control, enhancing the ability to attribute changes to the supplement.

## bp1348_q3 Calculate the percent change in the supplement group’s mean working memory score from baseline to 12 weeks.
Correct: A
Percent change = ((29.6‑28.4)/28.4)×100 ≈ 4.2%.

## bp1348_q4 Which of the following statements is a common trap when interpreting the study’s findings?
Correct: A
The study acknowledges that the observed improvement may be statistically significant but not necessarily clinically meaningful; claiming clinical significance is a trap.

## bp1348_q5 Which resource would best help a student understand how to interpret the statistical significance reported in this study?
Correct: A
Statistical significance is addressed in hypothesis testing and p‑values, which are covered in a textbook chapter on these topics.
