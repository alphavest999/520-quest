# BP1743

Researchers studied the effect of four different dietary supplements on the improvement of memory performance in adults aged 60–75. In a randomized controlled trial, 120 participants were assigned to one of four groups: Group A received supplement X, Group B received supplement Y, Group C received supplement Z, and Group D received a placebo. After a 12‑week intervention, memory was assessed using the Rey Auditory Verbal Learning Test (RAVLT). The results are summarized in Table 1. The researchers reported that Group A improved by an average of 12.5 points, Group B by 9.8 points, Group C by 7.4 points, and the placebo group by 3.1 points. Statistical analysis indicated that the improvements in Groups A, B, and C were significantly greater than placebo (p < 0.05). The authors concluded that supplement X was the most effective, followed by Y and Z, and suggested that further studies should explore the underlying mechanisms. The study also monitored participants' dietary intake and physical activity to control for confounding variables.

| Group | Supplement | Avg. RAVLT Improvement | p-value |
|-------|------------|------------------------|---------|
| A | X | 12.5 | <0.01 |
| B | Y | 9.8 | <0.05 |
| C | Z | 7.4 | <0.05 |
| D | Placebo | 3.1 | 0.30 |

## bp1743-1 Which group had the highest average improvement in RAVLT scores?
Correct: A
Table 1 shows Group A (supplement X) with an average improvement of 12.5 points, the highest among all groups.

## bp1743-2 Which experimental design would best test the hypothesis that supplement X improves memory performance?
Correct: A
A randomized controlled trial (RCT) is the gold standard for testing causal effects of an intervention, as used in the passage.

## bp1743-3 Calculate the average RAVLT improvement across all four groups.
Correct: A
Sum of improvements = 12.5 + 9.8 + 7.4 + 3.1 = 33.8. Dividing by 4 gives 8.45 points.

## bp1743-4 Which of the following statements is NOT supported by the data presented?
Correct: C
Supplement Z improved scores by 7.4 points, which is significantly greater than placebo (p < 0.05), so it does have an effect.

## bp1743-5 How might these findings influence clinical recommendations for older adults?
Correct: B
While the data suggest efficacy, clinical guidelines typically require replication and safety data before universal recommendation.
