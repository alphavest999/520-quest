# 520 Quest

A free, game-style MCAT study app with a landing page and Pro sales page. Static site on GitHub Pages.

- `/` landing page
- `/pro/` Pro sales page
- `/play/` the app (installable, offline)
- `config.js` holds the Gumroad link and price used by the site's buy buttons
